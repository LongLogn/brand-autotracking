# Memory

Lưu các quyết định, bối cảnh và bài học dự án có giá trị lâu dài. [project-context.md](project-context.md) là bản tóm tắt ngữ cảnh duy nhất cần đọc đầu phiên và rà soát cập nhật cuối phiên. Memory là tài liệu được quản lý trong Git, không phải bộ nhớ tự động của công cụ AI.

Phân biệt thông tin đã thống nhất với giả định hoặc nội dung cần xác nhận; dẫn đến tài liệu gốc khi có thể. Cập nhật khi thông tin thay đổi và không lưu mật khẩu, token hoặc dữ liệu nhạy cảm.
